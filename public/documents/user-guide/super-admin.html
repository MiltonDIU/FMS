Super Admin Guide

Faculty Management System · Daffodil International University

In short: you hold every permission. Everything in the Admin, Registrar and Research Team guides applies to you. This guide covers what only you can do: system settings, activation and bulk email, bulk import, completion scores, and the activity log.

Super Admin does not by itself let you approve profile changes. To decide a tab, add yourself or the Super Admin role to its Notification Routing.

1. System Settings

One page with one Save button. Its tabs:

TabWhat it controls
Maintenance ModeClose the public website for maintenance. The admin panel keeps working.
Teacher API IntegrationHR/ERP credentials and endpoint paths, with a button to test the connection
Teacher SettingsWhether a welcome email is sent, whether teachers may use Compare with ERP, and whether unverified profiles are hidden from the public site
Profile Integrity & ThresholdsHow completion scores are judged
Dashboard SettingsDashboard options
Mail ConfigurationThe mail server the system sends from
Frontend SettingsThe public theme (DIU, Modern, Ledger, Aurora, Lumina), colours, fonts and directory options
Profile DownloadsWhether visitors can download a teacher's CV (PDF) and vCard
Branding & Site IdentitySite name, logo, favicon, address, contact details, footer text
Data MigrationOptions for importing data from the old system

Hiding unverified profiles removes every profile whose teacher has not yet confirmed it. Switch it on only once most teachers have confirmed.

2. Activating teachers

  1. On Teachers, click Send Activation Email on the teacher's row (also on the teacher's view page).
  2. Set how many days the link stays valid and send.
  3. The teacher opens the link, sets a password and is signed in. Teachers who have already set a password are skipped.

The Teachers list shows activation progress: sent, activated, awaiting, expired or failed. The activation link is never click-tracked, so a mail scanner cannot use it up.

3. Emailing teachers

  • Send Email to Teachers (Teachers page header): target by faculties, departments, employment statuses and job types; the number of recipients is shown before you send. Then select an email template, adjust the subject and body, and for activation emails set the link validity and whether to skip teachers who have already activated. A person in several selected departments gets one copy.
  • Send Email to Selected: tick teachers in the list and use this bulk action.
  • Send Email on a row: one teacher.

Sent Emails shows each send and, per recipient, whether it was delivered, opened and clicked. Add bounced addresses to Blocked Emails; nothing is sent to them until unblocked. Only you can delete Sent Emails records.

4. Importing teachers in bulk

  1. Open Import Teachers (Bulk) and click Download Template.
  2. Fill the JSON file in the template's format.
  3. Upload it with Select JSON File and click Start Import.
  4. If rows fail, click Download Error Log, fix them and import those rows again.

Import options such as dry run, skip existing teachers and overwrite are on the Data Migration tab of System Settings.

5. Completion scores

  • Batch Calculate Completion Scores (Teachers page header): choose employment statuses, optionally force a re-sync or include archived teachers, check the count, and run.
  • Sync Selected Scores (bulk action) or Sync Score (one row) for a few teachers.

The Completion Score and Score Synced columns show the result.

6. Other teacher actions

  • Login Allowed switch on a row: stop or allow one teacher's sign-in.
  • Sync Photo: restore a teacher's missing photo from the legacy source.
  • Sync Old Data: re-import one teacher's data from the old system, choosing what to do with existing data.

7. Team Directory and Activity Log

  • Team Directory: every staff account with its roles, filterable by role. Use it to check who holds Admin, Research Team and similar roles.
  • Activity Log: who changed what, and when, across the system.

8. Name Prefixes and Academic Suffixes

Titles (Prof., Dr.) and qualifications (PhD) are kept as lists so every name is shown the same way on screens, CVs and the API. Edit them here; merge duplicates rather than deleting them.

9. Scopus runs

You can do everything in the Research Team's Scopus Review, and you are the only one who can Delete a run. A run is the record of what was reviewed and on what rules, so delete only when you are sure.
