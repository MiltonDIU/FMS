Administrator & Registrar Guide

Faculty Management System (FMS) · Institutional Administration

In short: create or import teacher profiles → send secure activation emails → sync & compare records with the University ERP → assign Spatie roles and permissions → run batch profile completeness scores for UGC/IQAC accreditation → manage active themes and university branding.

1. Creating teachers & sending activation emails

  1. In the admin panel, open Teachers → Create (or import via roster).
  2. Enter the teacher's Employee ID, Full Name, official institutional email, faculty, and primary department.
  3. To send them their first login link, open Email Batches or trigger the activation email action on the teacher's row.
  4. The teacher receives an email with an unguessable 64-character token valid for single-use password setup.
  5. The Email Batches screen tracks who opened and clicked their activation email.

2. ERP Synchronization & Conflict Resolution

To keep the faculty directory aligned with the central University ERP:

  • Under Teachers, open any teacher record and click Sync with ERP.
  • The modal displays FMS data on the left and live ERP API data on the right.
  • The engine maps: Employee details, Educations (CGPA, Marks, Total Marks, Division/Class), Job Experience, Awards, and Certifications.
  • You can inspect differences section-by-section and selectively overwrite or merge ERP data into FMS.

4. Batch Calculating Profile Scores

For institutional quality assurance (IQAC / UGC audit reporting):

  1. Open the Teachers list table.
  2. Select all teachers (or filter by specific department).
  3. From the bulk actions dropdown, select Batch Calculate Profile Scores.
  4. The system iterates through all selected faculty, runs the ProfileGapEvaluator, and updates their score (0–100%) and profile_score_synced_at timestamp.

5. Appearance, Branding & Active Theme

Under System Settings → Appearance Settings:

  • Active Theme: select among the 5 installed themes (Theme DIU, Lumina, Aurora, Ledger, Modern).
  • Branding: update university logo, favicon, site name, institutional address, contact email, and footer copyright text.
